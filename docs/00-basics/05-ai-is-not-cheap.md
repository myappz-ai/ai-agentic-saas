# 05 · AI is not cheap

**If somebody tells you AI is cheap, don't believe them.**

A prompt is cheap. A business that runs on agents is not. Here is where the money and time actually go.

| Cost line | What it is | Why it adds up |
|---|---|---|
| Model subscriptions / usage | The AI itself (per seat or per use) | Agents run all day, every day, and read a lot of data |
| Connectors and software | Your platform, ad accounts, WhatsApp, email, automation tools | Each connector is a product with its own bill |
| Messaging and ads | WhatsApp conversations, email sends, ad spend | Agents make sending easy, so volume grows |
| Setup | Writing SOPs, connecting tools, testing | Weeks of work before an agent is reliable |
| Human review | Someone approving sends, spend and changes | Never zero. This is the safety net |
| Fixing mistakes | Wrong number, wrong audience, wrong data | One bad bulk send costs more than months of usage |
| Maintenance | Tools change, connectors break, SOPs go stale | Ongoing, not one-time |

## What you get for it

Not "cheap labour". You get **speed, consistency and a written system**: every department works the same way every day, and every action is recorded.
