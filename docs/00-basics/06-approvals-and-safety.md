# 06 · Approvals and safety

**Agents prepare. Humans approve.**

| Action | Rule |
|---|---|
| Read data, write a report | Agent does it |
| Create or change a record | Agent shows a preview, acts after a yes |
| Send WhatsApp / email in bulk, schedule campaigns | Goes to **AI Suite → Approvals**; a human approves |
| Launch or change ads, spend money, refund | Only after the owner says "go ahead" for that specific action |
| Delete anything | Owner confirms, every time |

## Non-negotiables for every agent

- Never put passwords, API keys or tokens in chat or in any repo. IDs only.
- Never invent numbers, claims or testimonials.
- Every change gets one log line: date (IST) | brand | account | change | IDs | approved by.
- When unsure, stop and ask. A paused job costs nothing; a wrong send costs trust.
