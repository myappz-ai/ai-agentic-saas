# Examples (fake data)

> **Sample data.** Everything here is made up ("Acme Studio" is fictional). Replace it with your own facts in your **private** workspace, never in this kit.

Use these files to see what an agent-run company looks like before you build your own.

| File | What it shows |
|---|---|
| [sample-company/overview.md](sample-company/overview.md) | The shared facts every agent reads first |
| [sample-company/offers-and-pricing.md](sample-company/offers-and-pricing.md) | Offers and prices, written so an agent can quote them |
| [sample-company/systems-and-tools.md](sample-company/systems-and-tools.md) | Which connector does what, and known limits |
| [sample-company/decision-log.md](sample-company/decision-log.md) | Company-wide decisions and why |
| [reports/2026-01-15-morning.md](reports/2026-01-15-morning.md) | A sales agent's morning booking report |

To start your own workspace: make a **private** repo, copy `examples/sample-company/` to `company/`, copy [template/](../template) once per department to `agents/<nn>-<department>/`, and fill them in.
